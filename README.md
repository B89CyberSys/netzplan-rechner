# Netzplan-Rechner für Windows

Ein kleiner, einfacher Rechner für die Netzplantechnik – für Übungen und die praktische Planung echter Projekte.

## Funktionen

- FAZ, FEZ, SAZ und SEZ berechnen
- Gesamtpuffer (GP) und freien Puffer (FP) anzeigen
- Vorgänger berücksichtigen: FAZ = größtes FEZ der Vorgänger
- kritische Vorgänge markieren
- Einheiten: Stunden, Arbeitstage und Kalenderwochen
- mehrere zufällige FiSi-Beispiele
- Termine als `.ics` für Outlook oder Google Kalender exportieren
- keine Anmeldung, keine Installation und kein Internet nötig

## Download und Start

1. `Netzplan-Rechner-Windows.zip` herunterladen.
2. ZIP-Datei entpacken.
3. `Netzplan-Rechner.exe` starten.

Windows kann beim ersten Start eine SmartScreen-Warnung zeigen, weil die EXE nicht digital signiert ist. In diesem Fall nur fortfahren, wenn die Datei aus diesem Repository stammt.

Weitere Hinweise stehen in `ANLEITUNG.txt`.
